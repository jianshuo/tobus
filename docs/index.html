出门巴士

离开家里 Wi‑Fi 时，自动告诉你最近的东京都营巴士 東15、東16 还有几分钟到站。

功能

  • 去东京站 / 回家两种模式，按你离家的距离自动切换
  • 東15、東16 混排，按到站时间排序；每条线自动选离你最近、且会停的站
  • 内置都营巴士官方时刻表，自动区分平日、土曜、休日（含祝日）
  • 按车辆实时位置推算晚点，并显示还有几站
  • 回家时显示每班车到家门口那一站的时间
  • 配合「快捷指令」自动化，断开家里 Wi‑Fi 自动弹出通知

隐私政策

数据来源：公共交通オープンデータセンター（ODPT）提供的东京都交通局数据。本应用为个人开发，非东京都交通局官方应用。
